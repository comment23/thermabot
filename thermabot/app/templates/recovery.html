    Home Assistant survivability
    
  
    Loading connection status...
    
  
    If Home Assistant cannot be read, Thermabot clears stale readings, pauses writes and
    reconnects on the next tick. Your thermostat keeps its last settings; its own schedules
    and hardware protection must remain the final safety layer. A restart is not a safety restore.
    
  
    The optional HA package detects missing Thermabot heartbeats after 15 minutes,
    disables the enable mirror and creates an HA notification. It never writes climate settings.
    It cannot operate while Home Assistant itself is down.

    Restore safely, offline
    
  
    To restore only configuration, use the validated import above. To restore all SQLite data:
    
  
      
    
    1. Stop Thermabot completely. Keep a separate copy of the entire data directory, including
      any -wal and -shm files. Never overwrite a running database.
      2. 
    
    2. Use the same Thermabot version as the backup first. Verify the backup with
      sqlite3 backup.db "PRAGMA integrity_check;"; the result must be ok.
      3. 
    
    3. In an empty data directory, place the backup as thermabot.db. Preserve required
      file ownership and permissions. Do not copy old WAL/SHM files into it.
      4. 
    
    4. Before restarting, turn off HA's input_boolean.thermabot_enabled.
      Restored sessions and run state are sensitive. Restart, stop the bot in Controls,
      invalidate restored sessions, review settings and verify HA connectivity before enabling.
      5. 
  
    
  
    This interface deliberately does not replace a live database or restore secrets.
